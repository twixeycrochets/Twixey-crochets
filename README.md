# Twixey Crochet 🧶

A modern, responsive website template for a handmade crochet brand, built with Tailwind CSS and vanilla JavaScript.

## ✨ Features
- **Product Gallery:** Filterable showcase for handmade plushies and crochet patterns.
- **Interactive Shopping Cart:** Dynamic cart drawer with item management and subtotal calculation.
- **Yarn Yardage Estimator:** Built-in tool to help crafters estimate yarn requirements.
- **Custom Order Form:** Direct inquiry section for custom crochet commissions.

## 🚀 Getting Started
1. Clone the repository or download the ZIP.
2. Open `index.html` in any modern web browser to view the site locally.

## 🌐 Live Preview
You can deploy this instantly using **GitHub Pages**:
1. Go to your repository **Settings**.
2. Navigate to the **Pages** tab on the left sidebar.
3. Under **Build and deployment**, select **Deploy from a branch** (`main` / `root`).
4. Save and access your live link!
